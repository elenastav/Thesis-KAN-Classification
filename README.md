Diagnosing mild traumatic brain injury (mTBI) remains difficult because conventional structural imaging often misses the subtle neurophysiological shifts underlying the condition. To address this, this thesis presents an interpretable Magnetoencephalography (MEG) classification framework that pairs dynamic functional connectivity microstate analysis with Kolmogorov-Arnold Networks (KAN). The pipeline processes thresholded 90x90 functional connectivity graphs, breaks them down using normalized Laplacian eigenspectra, and groups them into two distinct network microstates via the Neural Gas algorithm. After sorting these states by eigenvalue criteria, the system extracts ten temporal and graph-theoretic metrics for each subject.

To account for class imbalance, random undersampling over 100 runs established a balanced dataset of 60 subjects. Model validation relied on a two-step approach: 5-fold stratified cross-validation on 48 training subjects for feature thresholding, followed by Leave-One-Out testing on 12 held-out subjects. While standard classifiers like SVM and MLP outperformed the KAN by 4 to 5% in raw accuracy, the KAN achieved a test accuracy of 0.707 ± 0.133 and an AUC-ROC of 0.760 ± 0.141. Crucially, the network went beyond black-box predictions by using learnable B-spline functions to isolate transition probability and lower-connectivity dwell time as the key mTBI biomarkers. This highlights how transparent architectures can offer neurophysiologically grounded insights without sacrificing predictive power.
